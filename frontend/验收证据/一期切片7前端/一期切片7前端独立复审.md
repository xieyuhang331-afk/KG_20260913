## 核验摘要

- org_admin 与 org_operator 权限分离，机构运营人员页头身份和只读能力一致。
- 写操作固定携带 Idempotency-Key 与最新 version；409 刷新权威状态且不自动重放。
- cursor 仅作为服务端签名的不透明字符串传递，不解析、不展示、不推导总页数。
- 401、403、404、409、422、429、503 与 COMMIT_OUTCOME_UNKNOWN 均保持正式错误语义。
- 平台端个人数据导出监督不提供用户文件下载入口。
- Continuation Handoff 的 DataScope 使用正式枚举并映射为安全业务文案。
- 1440×900、1280×800、1024×768 横向溢出均为 0，浏览器 Console Error 为 0。
- 页面、截图、日志与证据未发现 PII、PHI、JWT、Credential、内部 SQL 或文件路径泄漏。
- Backend、Migration、SQL、CI Workflow 与 package-lock 非预期差异为 0。
- Disposable PostgreSQL、容器、网络、卷、端口、临时控制器和凭据残留为 0。
