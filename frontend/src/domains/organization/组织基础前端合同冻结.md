## 领域边界

- `platform_org` 是总部、省、市、县四级平台治理树；`tenant` 是门店经营主体。
- Organization 不是第二套 tenant；树节点只承载治理关系，tenant 通过关联列表展示。
- `canonical` 与 `legacy` 均可读；`legacy`、`archived` 全部只读。
- 县级节点可展示，县管理员能力 `NOT OPEN`。
- 联系人、手机号、证照、法人、地址、客户数、营收、入驻时间、资料完整度、安全设置、通知设置和经营指标均为 `Deferred`，页面隐藏。
- cursor 是 opaque keyset；界面只展示上一批/下一批，不构造页码、总页数或总记录数。

## 页面与路由冻结

| 端 | 路由 | 页面 | 访问角色 |
|---|---|---|---|
| 平台 | `/platform/organizations` | 四级树、选中节点详情、关联 tenant、治理操作 | super_admin / province_admin / city_admin |
| 平台 | `/platform/organizations/:organizationId` | 同一页面的可深链选中态 | super_admin / province_admin / city_admin |
| 机构 | `/institution/organization` | 本 tenant 最小组织资料 | org_admin |

不为原型中的 `/platform/org`、`/institution/profile` 建立兼容别名，避免把已 Deferred 的富组织管理和富资料语义带入 V1。

## 页面—API 矩阵

| 页面能力 | 方法与路径 | 使用方式 |
|---|---|---|
| 四级树 | `GET /api/v1/platform/organizations/tree` | `include_archived` 仅 super_admin 可选 |
| 节点详情 | `GET /api/v1/platform/organizations/{organization_id}` | 选中节点或深链加载 |
| 关联 tenant | `GET /api/v1/platform/organizations/{organization_id}/tenants` | `include_descendants`、`cursor`、`page_size` |
| 管理员候选 | `GET /api/v1/platform/organizations/{organization_id}/admin-candidates` | 仅 super_admin，组件短期内存，不进 Query cache |
| 创建节点 | `POST /api/v1/platform/organizations` | super_admin；携带 `parent_expected_version` |
| 修改名称/管理员 | `PATCH /api/v1/platform/organizations/{organization_id}` | super_admin；携带 `expected_version` |
| 同父 children 排序 | `PUT /api/v1/platform/organizations/{parent_id}/children/order` | super_admin；完整 children 集合和 parent/child 版本 |
| 激活 | `POST /api/v1/platform/organizations/{organization_id}/activate` | super_admin；二次确认 |
| 停用 | `POST /api/v1/platform/organizations/{organization_id}/deactivate` | super_admin；二次确认 |
| 机构最小资料 | `GET /api/v1/organizations/me` | org_admin；assigned/unassigned |

## 角色矩阵

| 能力 | super_admin | province_admin | city_admin | org_admin |
|---|---:|---:|---:|---:|
| 平台树/详情/tenant | 全 Scope | 本省只读 | 本市只读 | 禁止 |
| archived 历史 | 可读 | 不可读 | 不可读 | 安全 404 |
| 创建/修改/管理员/状态/排序 | 允许 | 禁止且不渲染入口 | 禁止且不渲染入口 | 禁止 |
| `/organizations/me` | 禁止 | 禁止 | 禁止 | 允许 |

PA/CA 越 Scope 的资源统一按 404 展示，避免泄露资源存在性。

## 状态与错误矩阵

| HTTP / code | UI 处理 |
|---|---|
| 401 | 清理本地登录态并跳转登录页 |
| 403 / `ORGANIZATION_SCOPE_FORBIDDEN` | 显示无权访问；不展示写入口 |
| 404 / `ORGANIZATION_NOT_FOUND` | 显示不存在或不在当前 Scope；机构 archived 同样安全 404 |
| 409 / `ORGANIZATION_VERSION_CONFLICT` | 结束 mutation、禁止自动重放、刷新树与最新详情 |
| 409 / `ORGANIZATION_CODE_CONFLICT` | 在创建表单标记编码冲突 |
| 409 / `ORGANIZATION_STATE_CONFLICT` | 显示状态已变化并刷新 |
| 422 / `ORGANIZATION_PARENT_INVALID` | 标记父节点无效 |
| 422 / `ORGANIZATION_HIERARCHY_INVALID` | 标记层级规则不合法 |
| 422 | 显示安全字段校验提示，不回显原始错误体 |
| 503 / `ORGANIZATION_DATABASE_UNAVAILABLE` | 显示暂时不可用与重试入口 |

所有 loading、empty、error、retry 状态均须可区分；mutation 进行中禁用全部治理按钮。

## 治理语义冻结

- 创建：`org_name,org_code,org_type,parent_id,parent_expected_version`，`admin_user_id` 可选。
- PATCH：字段缺失表示管理员不变，`null` 表示解绑，integer 表示绑定；必须携带 `expected_version`。
- 排序：以 `items` 提交同一父节点的完整直接 children；不得跨父移动。
- activate/deactivate：携带 `expected_version` 和合同固定 `reason_code`；停用仅 `PLATFORM_GOVERNANCE | COMPLIANCE_HOLD`，激活仅 `GOVERNANCE_RESTORED`；所有治理 mutation 均二次确认。
- 创建父版本、PATCH、排序 parent/child 版本冲突后零自动重放。
- delete/archive/merge/transfer/reparent 均 `NOT OPEN`，页面不得出现入口。
