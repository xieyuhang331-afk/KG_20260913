> 边界：本文件只提供页面和后端合同冻结输入，不定义已存在的 API，不授权健管师 APP UI。

## 1. 业务边界

- 平台端负责健管师资质台账、资质审核和服务资格治理。
- 机构端负责邀请/绑定本机构健管师、人员台账及容量/工作状态的受控展示与操作。
- `SERVICE_READY` 是机构能否开展健康服务的聚合结论，不得由前端根据页面字段自行推导或伪造。
- 暂停、恢复、退出必须区分：暂停可恢复；自主退出有前置检查和冷却期；平台清退不可逆。本 Slice 只规划平台 Web 与机构 Web，不开发健管师 APP。

## 3. 页面—API 与字段需求矩阵

下列路径均为“能力需求名称”，不是已批准 API。后端应在规划阶段冻结最终 Typed OpenAPI、鉴权、错误码、分页与并发合同。

| 页面/动作 | 读取或写入能力 | 最小响应字段 | 最小请求字段 | 关键合同要求 |
|---|---|---|---|---|
| 平台台账 | 平台健管师分页查询 | `therapist_id, display_name_masked, level, qualification_status, earliest_expire_date, work_status, service_status, bound_tenant_count, version, next_cursor` | `status, risk, cursor, limit` | opaque keyset cursor；不可虚构总页数 |
| 平台详情 | 单个健管师详情 | 上述字段 + `specialty_codes, qualifications, bindings, work_status_history, review_history` | `therapist_id` | 平台 Scope；材料引用与展示字段分离 |
| 资质决定 | 资质审核 mutation | `review_id, qualification_status, version, decided_at` | `decision, reason_code?, comment?, expected_version, idempotency_key` | 服务端 `decided_at`；409 零写入且不自动重放 |
| 资质材料 | 私有文件临时查看 | 短期访问能力，不返回持久公网 URL | 当前密码/Step-up（待安全裁决） | 不进 URL、日志、缓存、快照、错误报告 |
| 机构邀请 | 邀请列表及 mutation | `invitation_id, display_name, status, expires_at, version, next_cursor` | 受邀对象标识、`expected_version, idempotency_key` | 不在列表返回手机号、身份证号或凭据 |
| 机构人员 | 本 Tenant 健管师分页 | `therapist_id, display_name, level, specialties, work_status, load_current, load_limit, qualification_risk, version, next_cursor` | `status, cursor, limit` | org_admin 仅本人 tenant；越权安全 404 |
| 暂停/恢复 | 工作状态 mutation | `work_status, version, changed_at` | `target_status, reason_code, expected_version, idempotency_key` | 状态机约束；409 后刷新，不重放 |
| 退出展示 | 退出前置检查与结果 | `eligible, blockers[], cooldown_until?, status` | 无或受控确认字段 | 前置检查服务端权威；本 Slice 不做 APP 自主退出 UI |
| SERVICE_READY | Tenant 服务就绪读取 | `tenant_id, tenant_active, service_ready, reason_codes[], checked_at, version` | `tenant_id` 或当前 tenant | 聚合结果与原因均由服务端返回 |

### 资质字段最小集

`qualification_id, qualification_type, certificate_number_masked, issued_at, expires_at, status, submitted_at, reviewed_at, version`。证照原图必须走私有文件短时授权；身份证号、手机号、地址、证照原始 URL 不进入台账响应。

### SERVICE_READY 原因建议冻结为枚举

至少需要覆盖：机构入驻未批准、机构已停用、无已通过资质的健管师、健管师未绑定、必修培训未通过、全部健管师暂停/退出、资质过期。前端只翻译服务端 code，不自行计算。

## 4. 状态机

### 资质审核

`DRAFT → SUBMITTED → UNDER_REVIEW → APPROVED | REJECTED | NEEDS_CORRECTION → RESUBMITTED`。终态是否允许重新提交、同一资质多版本关系和历史保留需后端明确。

### 工作状态

PRD存在 `available / offline / short_rest / long_rest / stopped / exited / expelled` 等语义；一期 Web 建议冻结为有限服务端枚举及允许迁移表。机构管理员是否可暂停/恢复、平台是否可强制操作必须单独授权，不能从原型按钮推断。

### 邀请/绑定

建议区分邀请 `ISSUED / ACCEPTED / EXPIRED / REVOKED` 与绑定 `PENDING / ACTIVE / REJECTED / TERMINATED`，禁止把邀请状态等同于在岗状态。

## 5. 错误与恢复矩阵

| HTTP | UI | 恢复方式 |
|---|---|---|
| 401 | 会话失效，不展示受保护数据 | 返回登录 |
| 403 | 当前角色无能力 | 保持只读/返回安全入口 |
| 404 | 对象不存在或越 Scope | 安全 404，不泄露存在性 |
| 409 | 版本或状态冲突 | 清理敏感状态、刷新详情，不自动重放 mutation |
| 422 | 字段/状态机校验失败 | 字段级提示；保留非敏感输入 |
| 429 | 频率限制 | 禁止连续点击，提示稍后重试 |
| 503 | 资质扫描/数据库/依赖不可用 | 明确“未执行”，提供刷新/重试 |

仍需冻结固定业务错误：资质不存在、材料未 CLEAN、资质版本冲突、非法状态迁移、邀请过期/撤销、绑定冲突、负载上限、退出前置条件失败、SERVICE_READY 计算不可用。

## 7. 原型与一期基线差异

| 原型表现 | 一期基线事实 | 处理 |
|---|---|---|
| 健管师资质台账、详情、风险和模拟统计均可见 | 当前生产前端无 therapist Web API Adapter 和生产页面 | 等合同；不复制 Mock 数据 |
