## 角色矩阵

- `org_admin`：仅访问当前 tenant 的邀请、入组、实名、分配和 PREPARING case。
- `super_admin`：访问平台会员实名终审与同意文档。
- `province_admin`、`city_admin`：不得看到或访问上述平台 Slice 3 写操作。
- Family/Therapist APP：本模块不交付 UI。

## 公共合同

- 新公共 ID 使用 branded UUIDv7 字符串；不引入 bigint。
- 列表仅使用 `cursor/limit/next_cursor`；不显示总页数。
- Mutation 全部发送 `Idempotency-Key`；状态变更携带 `expected_version`。
- 409 清除敏感状态并刷新，不自动重放。
- 503 `COMMIT_OUTCOME_UNKNOWN` 明确提示结果未知；其他 503 提示服务暂不可用。
- 400/401/403/404/409/429/503 使用固定安全文案，不显示原始 detail。
- PII、密码、短码不进入 URL、localStorage、sessionStorage、日志、错误报告、截图或 React Query cache。

## 状态与交互边界

- `short_code` 仅在 create/resend 成功后由页面组件内存一次性显示，关闭立即清除。
- PII 仅在 `pii-access` 成功后短时组件内存展示；离页、超时、403、409、决定完成立即清除。
- 审核决定必须提交当前 `revision_id` 与 `expected_version`。
- 不保留旧 `/api/v1/reviews/*identity*` approve/reject/step-up 路径。
- 同意文档后端没有列表 API；页面仅管理本次创建后返回的文档，不伪造历史列表。
