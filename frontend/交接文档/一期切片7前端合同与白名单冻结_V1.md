## DTO 与状态

- `ServiceFulfillmentDTO`: lifecycle、risk、五阶段 milestones、high-risk count、closing readiness、version。
- `TransferDTO`: source/target public identifiers、requested scope、transfer state、decision/closure facts、version。
- `ContinuationHandoffDTO`: authorized scope、handoff state、linked enrollment/service case facts、version。
- `DataExportDTO`: requested scope、export state、ready/expiry/download timestamps、version。
- `next_cursor`: opaque string；客户端只保存当前批次导航历史，不解析、不构造、不推导总页数。

写操作固定使用一次生成的 `Idempotency-Key` 与服务端最新 `version`。409 后重新 GET，不自动重放；`COMMIT_OUTCOME_UNKNOWN` 只提示查询权威状态，不换 Key 重提。

## 角色与操作矩阵

| 操作 | org_admin | org_operator | super_admin / sys_admin |
|---|---:|---:|---:|
| 机构履约/转机构读取 | 是 | 是 | 否 |
| pause / resume / terminate | 是 | 否 | 否 |
| transfer start-review / accept / reject / source-close | 是 | 否 | 否 |
| 平台履约、转机构、导出监督 | 否 | 否 | 是 |
| safety-terminate / coordinate-close | 否 | 否 | 是 |

未知状态和非法组合一律 fail-closed：展示“状态待核对”，隐藏写操作。

## 视觉冻结

- 沿用现有康邻蓝/青绿视觉、PlatformShell/InstitutionShell、1280px 内容区。
- 履约详情的标志性交互为 D0、D7、D14、D21、D28 五阶段轨道。
- 列表为全宽高密度信息；详情为主体与风险/状态侧栏；1024 宽度安全改单栏。
- 不展示客户 PII、PHI、JWT、Credential、内部 SQL、文件路径或下载 token。
- 后端只提供公共标识时，以短业务引用作为次级信息，不伪造客户姓名、机构名或统计。
