# 机构端门店入驻申请表 V1 合同与验收

## 权威输入

- PRD：`05_旅程①_门店入驻.md`。
- 创建：`POST /api/v1/tenants`。
- 列表：`GET /api/v1/tenants/my-applications`。
- 状态：`GET /api/v1/tenants/{tenant_id}/application-status`。

## 字段冻结

| 页面字段 | 创建请求字段 | V1 状态 |
|---|---|---|
| 门店名称 | `name` | 可提交 |
| 门店类型 | `type` | 可提交，使用 PRD 枚举显示值 |
| 统一社会信用代码 | `credit_code` | 可提交，18 位格式校验 |
| 医疗机构许可证号 | `license_no` | 医疗类条件必填 |
| 法定代表人 | `legal_person_name` | 可提交 |
| 省 / 市 / 区县 / 地址 | `province` / `city` / `district` / `address` | 可提交；当前无行政区字典接口，逐级填写并清空下级 |
| 联系人姓名 / 手机 / 邮箱 | `contact_name` / `contact_phone` / `contact_email` | 可提交；不进入本地草稿、URL、日志或证据 |
| 附件 | `license_image=null`、`attachments=[]` | 只做文件类型、大小、数量校验；不上传、不伪造 URL |
| 主营领域 | 无 | 不进入 payload，不静默丢弃 |

成功响应使用 `id` 跳转 `/institution/store/application/{id}/status`。本地草稿仅保存门店名称、门店类型、省、市、区县和地址；信用代码、许可证、法人、联系人和附件不持久化。

## 状态与错误

- 客户端字段失败：`validation_error`，焦点移动到首个错误。
- `409`：信用代码冲突，不自动重放。
- `422`：服务端字段校验失败，保留填写内容。
- `503`：服务不可用，保留填写内容并允许稍后重试。
- 其他错误：安全通用错误，不展示服务端原始正文。
- 提交期间使用同步请求锁与禁用按钮阻止重复提交。
