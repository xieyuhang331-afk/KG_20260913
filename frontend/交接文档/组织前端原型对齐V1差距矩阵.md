## 原型—现状 Gap

| 区域 | 原型目标 | 现状 | 分类 | 本模块处理 |
|---|---|---|---|---|
| 平台 Shell | 深色空间头、分组导航、面包屑、紧凑顶栏 | 白色基础侧栏，无上下文层级 | 可直接视觉还原 | 收敛品牌色、空间层级、当前路由和角色信息 |
| 机构 Shell | 与平台共享后台语言并保留门店角色差异 | 独立白色横向导航 | 可直接视觉还原 | 共享 Token、导航密度和焦点规范，保留机构语义 |
| 页面标题 | 背景上直接形成标题层级 | 模板化大卡片标题 | 可直接视觉还原 | 改为紧凑标题、说明和真实状态标签 |
| 组织树 | 左侧固定树、类型图标、选中态明显 | 树可用但层级弱 | 已有 API 支持 | 已关闭：1180 以上固定左树/右工作区，1024 安全单栏；强化层级线、类型、状态、选中同步和键盘焦点 |
| 当前节点 | 标题、路径、状态和操作同屏 | 详情卡与树割裂 | 已有 API 支持 | 建立路径—标题—状态—内容的同步头部 |
| 门店列表 | 高密度表格、等级/状态色、当前节点穿透 | 字段齐全但视觉密度弱 | 已有 API 支持 | 仅展示批准字段，保留 opaque cursor 上一批/下一批 |
| 治理操作 | 紧凑操作入口和二次确认 | 功能完整、样式基础 | 已有 API 支持 | 不改 mutation 语义，统一层级、禁用态和冲突反馈 |
| 机构资料 | 门店主体与组织路径一眼可识别 | 基础信息卡 | 已有 API 支持 | 突出门店状态、归属模式和四级路径轨道 |
| 区县层级文案 | 原型同时覆盖城区与县域节点 | 仅显示“县” | 已有 API 支持 | 统一显示“区/县”，创建仍提交 `county`，不新增后端类型 |
| loading/empty/error | 说明当前问题和下一步 | 通用消息块 | 已有 API 支持 | 增加恢复动作、语义图标与无障碍状态区域 |
| 负责人 | 原型表格列 | 最终 API 无此字段 | 需要新 API | Deferred；不显示、不推导、不伪造 |
| 客户数、营收、入驻时间 | 原型经营列 | 最终 API 无此字段 | 需要新 API | Deferred；不显示、不推导、不伪造 |
| 分配机构 | 原型按钮 | 合同未冻结 mutation | Deferred 或禁止 | 不实现 |
| 删除、合并、迁移 | 原型存在“移除”等动作 | Foundation V1 明确禁止 | 禁止 | 不实现 |
| 搜索、风险、待办数字 | 原型 Shell 的 Mock 能力 | 当前无聚合 API | 需要新 API | 不展示静态数字，不制造不可用入口 |

除明确标记 Deferred 或禁止的区域外，授权范围内 Gap 已关闭。
