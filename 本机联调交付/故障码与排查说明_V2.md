# G1 故障码与排查说明 V2

| 稳定码 | 含义 |
|---|---|
| `KG_LOCAL_PREREQUISITE_FAILED` | 必需工具或 Docker Desktop 不可用；脚本不自动安装 |
| `KG_PACKAGE_SOURCE_INVALID` | exact commit/tree 或源码文件无效 |
| `KG_PACKAGE_LOCK_INVALID` | Python/前端锁不存在或 frozen 安装失败 |
| `KG_PACKAGE_MIGRATION_HEAD_INVALID` | Migration 非单一 Head 或与 Manifest 不符 |
| `KG_PACKAGE_FORBIDDEN_ARTIFACT` | 包中发现 Git、venv、node_modules、env、日志或 JUnit |
| `KG_PACKAGE_MANIFEST_MISMATCH` | 文件 bytes/SHA/path 无法复算 |
| `KG_LOCAL_CONTAINER_NOT_READY` | 本任务数据库/RabbitMQ/ClamAV 容器未健康 |
| `KG_LOCAL_SCANNER_CONFIGURATION_INVALID` | S1 Scanner 配置、签名卷或固定镜像准备失败 |
| `KG_LOCAL_READINESS_INCOMPLETE` | API、依赖、Worker 或 Web 任一未就绪 |
| `KG_LOCAL_ALREADY_RUNNING` | 当前 run 仍有已记录进程；先检查状态或显式停止，拒绝重复启动 |
| `KG_LOCAL_CAPABILITY_BLOCKED` | Scanner/外部能力未提供，明确阻断 |
| `KG_LOCAL_BUSINESS_FIXTURE_NOT_IMPLEMENTED` | G2–G5 合成业务初始化未实现 |
| `KG_LOCAL_CLEANUP_SCOPE_INVALID` | run_id、label、路径或状态不一致，拒绝删除 |

所有错误只输出稳定码，不回显 URL、密码、Token、PII/PHI 或内部绝对路径。
