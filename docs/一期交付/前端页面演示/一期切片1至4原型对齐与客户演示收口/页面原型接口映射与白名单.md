## 原型差距分类

| 差距 | 分类 | 本轮处理 |
|---|---|---|
| Shell 使用临时图标代替正式品牌标识 | 可直接视觉还原 | 使用权威康邻智汇 Logo 资产 |
| 平台与机构导航为平铺列表 | 可直接视觉还原 | 仅按已有路由做业务分组，不新增入口 |
| 个别页头出现 `Platform Web`、`CONTROLLED ONBOARDING`、`P1`、`API` | 可直接视觉还原 | 改为客户可理解的中文展示语 |
| 页面卡片、宽屏双栏和 1280 内容宽度 | 已有实现 | 保持，不机械重排 |
| 健康档案缺少明确的会员/服务案例上下文 | 已有 API 支持 | 使用现有脱敏对象标识和服务状态强化上下文 |
| 病史、过敏、用药、症状、报告原文、AI 摘要、趋势、诊断 | Deferred/禁止 | 不展示、不伪造 |
